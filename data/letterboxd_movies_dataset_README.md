# Letterboxd Movies Dataset Dataset

## Overview
This dataset contains movie data scraped from Letterboxd.

## Dataset Information
- **Total Records**: 16,246
- **Columns**: 28
- **File Size**: 8.63 MB
- **Created**: 2025-10-08

## Columns Description

| Column | Type | Description |
|--------|------|-------------|
| title | str | Movie title |
| year | int | Release year |
| decade | int | Release decade |
| runtime | int | Movie duration in minutes |
| runtime_category | str | Runtime category (Short/Standard/Long/Epic) |
| genres | str | Movie genres (comma-separated) |
| primary_genre | str | Primary/first genre |
| genre_count | int | Number of genres |
| country | str | Country of origin |
| language | str | Primary language |
| description | str | Movie description/synopsis |
| title_length | int | Number of characters in title |
